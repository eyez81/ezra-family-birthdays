# לוח ימי ההולדת של משפחת עזרא

אתר סטטי ורספונסיבי שמוכן ל־GitHub Pages. אין צורך בהתקנה או בבנייה.

## הוספה או שינוי של בן משפחה

פותחים את הקובץ `familyData.js`. כל אדם מופיע בשורה אחת. בראש הקובץ יש הסבר על סדר הנתונים ועל חיבור בני משפחה לפי המזהים.

```js
[25, "אייל עזרא", "1981-11-20", "זכר", false, 26, [23, 24], [37, 56, 67]],
```

- `25` הוא המזהה הייחודי של האדם.
- `26` הוא המזהה של בן/בת הזוג; אם אין, כותבים `null`.
- `[23, 24]` הם המזהים של ההורים.
- `[37, 56, 67]` הם המזהים של הילדים.
- הערך `false` שאחרי המגדר מציין שהאדם אינו נפטר. לנפטרים משנים אותו ל־`true`.
- כדי להסתיר אדם מהלוח ולהשאירו בעץ המשפחה, מוסיפים `false` נוסף בסוף השורה.

הגיל, לוח השנה, רשימת ימי ההולדת הקרובים ועץ המשפחה מתעדכנים אוטומטית. לחיצה על שם פותחת את פרטיו, ומשם ניתן לעבור לבן משפחה אחר.

## הוספה ליומן

- בחלון של כל אדם יש כפתור להוספת יום ההולדת שלו כאירוע שנתי ב־Google Calendar.
- הכפתור בראש האתר מוריד קובץ `ezra-family-birthdays.ics` ובו כל ימי ההולדת כאירועים שנתיים.
- אנשים שמסומנים כנפטרים אינם נכללים בקובץ הכללי.
- את הקובץ מייבאים ב־Google Calendar דרך הגדרות ← ייבוא וייצוא ← ייבוא.

## פרסום ב־GitHub Pages

1. מעלים את כל קבצי התיקייה למאגר GitHub.
2. נכנסים ל־Settings → Pages.
3. בוחרים Deploy from a branch, את הענף `main` ואת התיקייה `/root`.
4. שומרים וממתינים לפרסום הכתובת.
